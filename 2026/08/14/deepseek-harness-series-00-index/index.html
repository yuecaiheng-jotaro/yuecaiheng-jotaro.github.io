这组文章按 DeepSeek Harness 的真实工程边界拆分，而不是按目录机械罗列。每篇都可以单独发布；合起来是一套从运行入口到扩展开发的源码阅读路线。

专栏文章

  1. 启动与组合：Profile、Bundle、Patch 如何拼出运行时
  2. 核心 Agent Loop：Turn、Step、Inbox 与取消收敛
  3. Session Log：为什么模型可见内容必须可重建
  4. System Prompt：Prompt Section、变量、工具 schema 如何组装
  5. Tools：从函数调用到可审计工具流水线
  6. LLM：模型 adapter、streaming、retry 与 token meter
  7. FS/Shell/Sandbox：本机能力如何被策略化
  8. Session Data Plane：持久化、Projection、Title、Query
  9. Web UI：Host、Client、Remote 与 Slot 插件
  10. API/Typert/SDK/ACP：跨进程调用和自动化协议
  11. Subagent、Jobs、Workflow：长任务与多 Agent 协作
  12. Interaction、Permission、Plan、Goal：人机协作控制面
  13. Storage、Attachment、Spill：大对象和附件如何进入 Agent
  14. Skill、MCP、Extensions：外部能力如何动态进入 Harness
  15. Testing、Docs、Agent Notes：这个仓库为什么校验这么重
  16. Package Map：按 packages 分组继续逐包阅读

推荐阅读顺序

先读 01、02、03，建立启动和 loop 主线；再读 05、07，理解 Agent 能力为什么不能直接裸调系统资源；然后读 09、10，理解 Web 和外部协议如何接入；最后读 11、12，看复杂协作能力如何保持在插件边界内。
